**Curso:** Construcción de Software

## 📋 Descripción del Proyecto
Sistema de gestión de citas médicas en línea para la red de clínicas **CitaSalud Arequipa**, diseñado para soportar picos de alta concurrencia (especialmente la apertura de agenda matutina entre las 7:00 a. m. y 7:15 a. m.), garantizando disponibilidad, rendimiento y la correcta sincronización de agendas médicas sin sobreventas.
